and that auto-attach remains a frozen separate caller. It is held because the standalone
preparatory split is not executable as a coherent next step. The same public consumer path must

1. the new authority-managed public transport path;

## Exact prohibitions

On the authority-managed public path, A1.3-P0 must not reuse the existing legacy
`launch_hidden_owner_helper` semantics unchanged. It specifically prohibits:

- `wait_for_hidden_owner_helper_readiness`;
- `reconcile_hidden_owner_helper_start_timeout`;
- `stabilize_hidden_owner_helper_start_return`;
- joined readiness or continuity receipt reconstruction;
- legacy `persist_orchestration_session` or `persist_participant` authority writes; and
- any startup or terminal inference derived from readiness, process posture, PID, helper/socket
  state, timeout, EOF, prompt delivery, or local adapter errors.

If the public transport split cannot be implemented inside the named fence without changing
HostSessionAuthority or StateStore schemas, persistence semantics, auto-attach behavior, endpoint
design, receipt/supervisor/member-runtime ownership, or broader lifecycle meaning, the packet must
stop for separate authority.
