## Full cleanup plan and holds

All allocations in historical records are point-in-time measurements, not current reclaim. Nested rows are nonadditive; hardlinks, live processes, mount boundaries, unique inputs and protected references can reduce reclaim. The audit's approximately 47 GiB canonical-debug historical ceiling is not a current safe-reclaim or capacity promise. The completed action removed selected eligible descendants of canonical `target/debug`; other descendants remain for assessment:

1. **B1** selected compiler incremental files were removed after source, input, record, reference and live preflights. Remaining locks and multiply-linked files are held for assessment.
2. **B2** selected debug library archives and metadata were removed independently of B1. Other debug contents, including generated or unclassified inputs and outputs, remain for subset-specific assessment; continue to protect active executables, references, symlinks and hardlinks.
3. **B3** integration checkout debug artifacts: later work only, with the frozen actor and all aliases, its World/Lane workflow, enclosing evidence and full dependency closure protected.
4. **B4** isolated inventory target: retain private original proof and source until selected and preserved.
5. **B5** comparison roots: preserve each base/head source and original results; GitHub custody remains unverified.
6. **B6** other repository and worktree candidates: 24 worktrees have been removed in the two Task03 batches; preserve each remaining repository's exact source, changes, inputs and selected records, check ownership and remote restoration, and never infer eligibility from age or directory name.
7. **B7** mixed, loose and temporary roots: classify source, results, private configuration, caches and unrelated repositories before any separate disposition. Preserve shared Cargo state, installed files, backups and rollback dependencies. Runtime/session records and protected workflow trees remain local and are not publication payloads.

Four historical lock hashes and two Git metadata probes were unavailable in the accepted audit; affected source groups remain held until resolved. Historical R2 command, cwd/time or outcome metadata is incomplete where the manifest says so. Other original results and private custody remain unselected for many groups. Missing original binary history alone does not prevent eligible cleanup, but a rebuilt artifact is not an original result. Do not remove a path or ancestor containing a protected dependency. Do not use `cargo clean`, `git clean` or pruning. A dirty worktree may be removed with an exact reviewed `git worktree remove --force` command only after its complete source and record preservation and the applicable checks are established. Full audit and subsequent batches are future work, not permission for this increment.
